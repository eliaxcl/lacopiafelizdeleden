# Chile, La Copia Feliz del Edén — versión definitiva

Sitio estático listo para publicación.

## Contenido de esta versión
- Identidad editorial chilena.
- Concepto de ecosistema con personajes que dejan huellas.
- Serie 01: **La Vieja Sapa**, observadora y picarona chilena.
- Inspiración narrativa en los siete principios del **Kybalión**.
- Mensaje: aprender del mundo, reinterpretar y crear algo propio.
- Páginas legales existentes: privacidad y términos.
- `robots.txt` y `sitemap.xml`.
- Diseño responsive para computador y móvil.
- Espacios preparados para futura publicidad y YouTube.

## Publicación
Subir el contenido de esta carpeta a la rama `main` del repositorio:
`https://github.com/eliaxcl/lacopiafelizdeleden`

Luego activar GitHub Pages o el método de despliegue que se haya elegido y asociar:
`lacopiafelizdeleden.cl`

## Nota
Los espacios de publicidad y newsletter están deliberadamente preparados, pero no activan servicios de terceros hasta configurarlos.
